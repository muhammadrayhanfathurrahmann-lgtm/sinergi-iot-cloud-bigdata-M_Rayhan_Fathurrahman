Tahap 01 • Perekaman Data Ground Truth

Internet of Things (IoT): Menangkap Realitas Fisik

Perangkat IoT bertindak sebagai organ sensorik yang membaca fenomena fisik di lapangan tanpa ketergantungan input manual manusia.

Peran Kunci dalam SI

Menghilangkan jeda manual. Mengonversi suhu, vibrasi, koordinat GPS, dan tekanan menjadi sinyal digital terukur seketika.

Protokol Komunikasi Ringan

Menggunakan protokol hemat energi seperti MQTT, CoAP, dan LoRaWAN yang sangat efisien untuk bandwidth rendah.

Karakteristik & Batasan

Mikrokontroler IoT memiliki RAM dan prosesor mikro. Mereka tidak dirancang untuk menyimpan atau mengolah data raksasa di perangkat.

IoT Sensor Node: ESP32-S3-PRO AKTIF • 200 Hz
Suhu Kontainer -20.4°C Batas Toleransi: -22°C s/d -15°C
Vibrasi Kompresor 0.03 g Getaran Dinamik Normal
Payload: 48 Bytes MQTT Baterai: 94% (Power Saving)
Tahap 02 • Ingestion & Penampung Skalabel

Cloud Computing: Transmisi & Infrastruktur Elastis

Karena sensor IoT terbatas, Cloud Computing bertindak sebagai jalan tol penampung untuk menyatukan ribuan titik data tanpa bottleneck.

Elastisitas On-Demand

Komputasi dan memori otomatis membesar saat data melonjak, tanpa perlu membeli atau merawat server fisik lokal.

Message Broker & Data Lake

Mengelola antrean aliran data masif melalui layanan seperti AWS IoT Core, GCP Pub/Sub, dan penyimpanan S3/Blob.

Ketersediaan Tinggi (High Availability)

Penyimpanan multi-zona menjamin data selalu dapat diakses oleh Sistem Informasi kapan saja tanpa risiko *server down*.

Data Lake S3 Shard (Zone-A) Replika Sinkron
Total Ingest 88.2 MB/dtk
Failover Auto-Active
Tahap 03 • Pengolahan Kognitif & Kecerdasan

Big Data Analytics: Mengubah Data Menjadi Insight

Tumpukan miliaran baris log IoT di Cloud diproses menggunakan algoritma terdistribusi dan Machine Learning untuk menghasilkan prediksi.

Pemrosesan Terdistribusi (5V)

Mengurai data masif (Volume, Velocity, Variety, Veracity, Value) secara paralel dengan engine seperti Apache Spark.

Penyaringan Anomali Mesin

Model AI membedakan fluktuasi wajar dari kerusakan nyata, mendeteksi anomali suhu sebelum barang mengalami pembusukan.

Analitik Prediktif Masa Depan

Bukan sekadar mencatat sejarah, Big Data memperkirakan kegagalan armada beberapa jam sebelum peristiwa tersebut terjadi.

Rangkuman Sinergi Trinitas Data
Tanpa IoT:

Sistem Informasi kekurangan data lapangan (*ground-truth*) dan buta terhadap kondisi fisik.

Tanpa Cloud:

Data IoT terisolasi di perangkat lokal dan tidak ada infrastruktur untuk menampung skala besar.

Tanpa Big Data:

Data masif hanya menjadi beban penyimpanan ("data swamp") tanpa menghasilkan pola cerdas.

Dengan Sinergi Ketiganya:

Terwujud Sistem Informasi Berbasis Data yang prediktif, otonom, terukur, dan bernilai tinggi.
